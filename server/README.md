# Punctuation Service

FastAPI + ONNX Runtime wrapper around
[`oliverguhr/fullstop-punctuation-multilingual-base`](https://huggingface.co/oliverguhr/fullstop-punctuation-multilingual-base)
(XLM-RoBERTa base, token classification) that the iOS app posts
finalized transcripts to for punctuation + sentence casing.

Design doc: `../punctuation-service-plan.md`.
Client integration: `../VoxLocal/VoxLocal/Services/PunctuationClient.swift`.

## Local — native Python

One-time model export (downloads ~1 GB from Hugging Face, exports to
ONNX, quantizes to INT8 — takes 3–5 minutes):

```bash
cd server
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt -r requirements-export.txt
python export_model.py
```

Run the server:

```bash
# API key must match the iOS client's PunctuationConfig — the default is
# `dev-key-change-me` so this is a local-dev no-op, but keep it explicit.
PUNCTUATION_API_KEY=dev-key-change-me \
  uvicorn app:app --host 127.0.0.1 --port 8000
```

Smoke-test:

```bash
curl -s http://127.0.0.1:8000/healthz
curl -s -X POST http://127.0.0.1:8000/punctuate \
  -H 'Content-Type: application/json' \
  -H 'X-API-Key: dev-key-change-me' \
  -d '{"text": "hello world how are you"}'
# -> {"text": "Hello world how are you?"}
```

Then ⌘R in Xcode; the iOS app defaults to `http://127.0.0.1:8000` and
`X-API-Key: dev-key-change-me`, so no client-side config change needed.

## Local — Docker

```bash
cd server
python export_model.py      # once, same as native path
docker build -t voxlocal-punctuation .
docker run --rm -p 8000:8000 \
  -e PUNCTUATION_API_KEY=dev-key-change-me \
  voxlocal-punctuation
```

The Dockerfile expects `model-onnx/` to be present in the build context
(it's gitignored). Run `export_model.py` first to generate it.

## Artifacts the container needs

`model-onnx/` (generated by `export_model.py`):

- `model.int8.onnx` — quantized model weights (~140 MB)
- `tokenizer.json` — XLM-R tokenizer (Rust `tokenizers` library compatible)
- `config.json` — model config, read at startup for `id2label`
- `special_tokens_map.json`, `sentencepiece.bpe.model` — left over from
  export, not strictly required at runtime but cheap to ship

## Knobs

Environment variables:

- `PUNCTUATION_API_KEY` (default `dev-key-change-me`) — required header
  value on every `POST /punctuate`
- `MODEL_DIR` (default `./model-onnx`) — where to find artifacts
- `MODEL_FILENAME` (default `model.int8.onnx`) — filename under `MODEL_DIR`
- `NUM_THREADS` (default = CPU count) — ONNX intra-op threads

## Operational notes (from the service plan)

- `/healthz` returns 503 until the lifespan hook finishes loading the
  model. ALB health checks should use this so traffic isn't sent to a
  cold task.
- One uvicorn worker per container. Threading happens inside ORT.
- Reject inputs > 2000 chars at the edge (413).
- INT8 quantized XLM-R base is ~140 MB resident. 2 GB RAM is plenty,
  4 GB gives headroom for bursty request sizes.
